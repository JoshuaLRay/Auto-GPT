# Squarespace Build Kit — Dustin Yelton Painting & Cleaning

Squarespace can't be built programmatically (no API, no CLI, no file/git
access — it's a GUI-only platform). So this kit gives you everything Claude
*can* produce to make the manual build fast and decision-free:

| File | What it is |
|------|------------|
| `BUILD-GUIDE.md` | Step-by-step: account → template → pages → form → SEO → launch |
| `COPY.md` | Every line of website copy, page by page, ready to paste |
| `custom-css.css` | Brand styling to paste into Squarespace **Custom CSS** |

The live static site in `../dustin-yelton-site/` is the visual reference —
build the Squarespace version to look and read like that.

## The honest tradeoff

- **Static site (already built):** free, fully working today, zero maintenance,
  but you (or a dev) edit HTML to change content.
- **Squarespace:** ~$16–23/mo, but Dustin can edit text/photos himself with no
  technical skill, and the contact form + hosting are built in.

Recommendation: show Dustin the **live static POC** first (it's the "wow"),
then if he wants to self-manage content long-term, spend ~2–4 hours building
the Squarespace version from this kit.

## Quick facts for the build

- **Platform version:** Squarespace **7.1** (current — every new site is 7.1).
- **Template:** 7.1 doesn't really use "templates" anymore — every site shares
  one flexible system and you style with **Fluid Engine** sections. Start blank.
- **Plan:** the **Business** plan ($23/mo monthly, less annually) unlocks the
  contact form + custom CSS; the cheaper Personal plan also allows CSS but has
  fewer features. Either works for this site.
- **Estimated build time:** 2–4 hours following `BUILD-GUIDE.md`.
